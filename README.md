# 🌦️ Weather Dashboard

A responsive weather dashboard that displays real-time weather information for cities around the world using the **Open-Meteo API**.

## 🌐 Live Demo

You can view the live Weather Dashboard here:

https://anubhav07-hub135.github.io/Weather-Dashboard/

## 🚀 Features

* Search weather by city name
* Displays current temperature
* Displays weather conditions
* Shows humidity percentage
* Shows wind speed
* Dynamic weather icons
* Loading indicator while fetching data
* Error handling for invalid city names
* Responsive design for desktop and mobile devices
* Press Enter to search
* No API key required

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Open-Meteo Weather API
* Open-Meteo Geocoding API

Weather-Dashboard/

## ⚙️ How It Works

1. The user enters a city name.
2. The Open-Meteo Geocoding API converts the city name into latitude and longitude coordinates.
3. The Open-Meteo Weather API retrieves the current weather information for those coordinates.
4. JavaScript dynamically displays the weather information on the dashboard.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter a city name and click **Search**.
